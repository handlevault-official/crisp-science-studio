# Crisp Science Studio 🔬

A local-first, offline-capable science workshop and lab calculator built for students, researchers, and science enthusiasts. Part of the **Crisp Suite / HandleVault** ecosystem.

## ✨ Features

- **Lab Solvers:** Instant calculation tools for Density ($d = m/v$) and Ideal Gas Law ($PV = nRT$).
- **Unit Converters:** Seamless conversion for Temperature (°C, °F, Kelvin) and Pressure (atm, kPa, mmHg/Torr, psi).
- **Night/Day Shift Themes:** Ergonomic high-contrast themes designed for late-night lab work or bright daytime studying.
- **100% Offline & Private:** Runs entirely client-side in your browser with zero login walls or external server tracking.
- **Single-File Architecture:** Lightweight, fast, and easy to deploy or modify.

---

## 🚀 Quick Start / Usage

1. Clone or download the repository.
2. Open `index.html` in any modern web browser.
3. (Optional) Deploy instantly via GitHub Pages using the included GitHub Actions workflow.

---

## 📂 Repository Structure

- `index.html` — The core single-file application (UI, logic, and styling).
- `repo.js` — Shared Crisp Suite repository metadata helper.
- `manifest.json` — Progressive Web App (PWA) manifest configuration.
- `requirements.txt` — Utility and development dependencies.
- `.github/workflows/deploy.yml` — Automated GitHub Pages deployment pipeline.
